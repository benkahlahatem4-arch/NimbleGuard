# NimbleGuard

واجهة سطح مكتب عربية وخفيفة لفحص الملفات محلياً والعناية الآمنة بالنظام على Windows.

## تشغيل التطبيق الجاهز (بدون Python أو نافذة أوامر)

انقر مرتين على [NimbleGuard.exe](<E:\New folder\dist\NimbleGuard.exe>). هذه نسخة مستقلة تحتوي على كل ما يحتاجه التطبيق؛ لا تحتاج إلى كتابة أوامر بعد الآن.

قد يستغرق أول تشغيل عدة ثوانٍ لأن النسخة التنفيذية تفك مكوّناتها مؤقتاً، وهذا طبيعي.

## تشغيل نسخة التطوير بالنقرة

يتطلب Python 3.10 أو أحدث.

بعد تثبيت المتطلبات مرة واحدة، انقر مرتين على [Launch_NimbleGuard.vbs](<E:\New folder\Launch_NimbleGuard.vbs>). سيظهر NimbleGuard كتطبيق عادي، بلا نافذة أوامر.

يمكنك أيضاً إنشاء اختصار لهذا الملف ووضعه على سطح المكتب.

## التثبيت الأول فقط

```powershell
py -m pip install -r requirements.txt
```

إذا لم يتوفر الأمر `py`، استخدم الأمر `python` بدلاً منه.

## ما يفعله الإصدار الأول

- فحص ملف أو مجلد عند الطلب فقط، وبحد أقصى 4,000 ملف، فلا يبقى فحص ثقيل في الخلفية.
- زر فحص سريع لمجلد التنزيلات، مع إبقاء الفحص في الخلفية معطلاً افتراضياً.
- تصنيف قابل للتفسير بناءً على الامتداد، الاسم، المكان، مؤشرات السكربت والتغليف وبصمة SHA-256.
- يفرّق بين **«كراك أو لعبة معدّلة — مراجعة»** و**«خطر مرتفع»**؛ فالنسخ المكركة مخاطرة أمنية وقانونية، لكنها ليست دليلاً كافياً وحده على فيروس.
- فحص توقيع Windows لملف محدد عند الطلب؛ لا ينفذ فحص التواقيع على آلاف الملفات.
- تكامل اختياري مع Microsoft Defender: عرض حالة الحماية اللحظية وتاريخ التواقيع، تحديث التواقيع، وفحص سريع أو كامل للنظام عند ضغط المستخدم للزر.
- عزل اختياري للملفات المريبة داخل `%LOCALAPPDATA%\NimbleGuard\quarantine` مع استعادة إلى المكان الأصلي أو مجلد تختاره، وحذف نهائي بعد تأكيدين.
- صفحة برامج بدء التشغيل لحساب المستخدم فقط؛ يمكن تعطيل أي برنامج واستعادته، من دون حذف أو إيقاف أي عملية تعمل حالياً.
- عرض التطبيقات الأكثر استهلاكاً للذاكرة، وتصدير تقرير فحص HTML محلي.
- زر «خفّف الجهاز الآن» يحذف ملفات TEMP القديمة في حساب المستخدم ضمن حد زمني وعددي آمن. لا يلمس مجلدات الصور والمستندات والتنزيلات ولا يقتل البرامج أو يغيّر السجل أو ملفات النظام.

## حدود أمان مهمة

هذا مشروع مساعد محلي وليس بديلاً عن Microsoft Defender أو محرّك مكافحة فيروسات مزوّد بتواقيع محدثة. لا تعزل أو تحذف ملفاً مهماً قبل مراجعة مصدره أو فحص بصمة SHA-256 لديه بمحرك موثوق. لا يرسل NimbleGuard الملفات أو البيانات إلى الإنترنت.
