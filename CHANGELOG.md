# Changelog

All notable changes to NimbleGuard are documented here.

## [0.6] - 2026-07-29

### Added

- Clear button-style sidebar navigation.
- Microsoft Defender status, signature update, and quick/full scan controls.
- Optional lightweight Downloads monitoring.
- Startup-item review with reversible disable and restore.
- Manual local quarantine and restore.
- Safe current-user temporary-file cleanup.
- Arabic, English, and French interface options.

### Security

- No automatic deletion or quarantine.
- Local file-review indicators are explained to the user and do not claim certainty.
- Microsoft Defender remains the actual antivirus scanning engine.
