# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.6 Beta | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please do **not** publish a security vulnerability, proof-of-concept malware, private token, or sensitive personal data in a public Issue.

Use GitHub's private vulnerability-reporting feature from the repository's **Security** tab when it is enabled. Include:

- A clear description of the impact.
- Safe reproduction steps.
- The NimbleGuard version and Windows version.
- Any suggested mitigation.

The maintainer will acknowledge reports as soon as reasonably possible. Do not expect a public fix date until the issue has been assessed.

## Scope

This policy covers the NimbleGuard source code and official release assets published by this repository. It does not cover Microsoft Defender, Windows, third-party applications, or unofficial reuploads.
